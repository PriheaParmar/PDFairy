Privacy Policy

Last updated: 22 September 2026

What PDFairy processes

PDFairy processes files you deliberately select. Supported image conversions can occur entirely in your browser. PDF and document operations send the selected file to the PDFairy server hosting the page.

File lifecycle

The server validates and processes most uploads in memory and returns the result in the same request. It does not intentionally retain uploads or generated results. When enabled, Office conversion writes the upload and converted output inside a per-request temporary folder with a separate LibreOffice profile. The folder is removed after success or handled failure. A forced machine or process failure can leave temporary data; a later server startup removes stale PDFairy Office folders once they are older than 24 hours.

Logs and third parties

PDFairy does not include accounts, analytics, advertising, cookies, browser local storage, or third-party file-processing services. Optional application logs contain a request ID, endpoint, status, duration, file count, aggregate byte count, and generic error category; they do not contain document contents, extracted text, file bytes, or complete filenames. A hosting provider or reverse proxy may keep separate operational logs under its own policy.

Your browser

The selected file and generated result remain in browser memory for the current page session. Refreshing or closing the page clears that session state. A downloaded result remains wherever your browser saves it.

Security and deployment

Uploaded documents are untrusted and are not claimed to be malware-scanned. A public deployment must use HTTPS and isolate document processing from application secrets, the host filesystem, internal networks, and other users' files. Password-protected PDFs are rejected and must be unlocked before processing.
