Plain-language privacy

Your session stays yours.

PDFairy has no accounts, analytics or third-party file services. Browser image tasks stay in this browser. PDF and document tasks are sent to the PDFairy server hosting this page.

Uploads and generated files are held in memory for the request and are not intentionally retained. Office conversion uses an isolated temporary folder that is removed after success or failure; stale folders from an interrupted server are cleared after 24 hours on the next start.

Document contents and full filenames are not written to application logs. Your browser keeps the selected file and result only for the current page session.
